Политика конфиденциальности Infra Backups

Infra Backups — личное приложение владельца для резервного копирования. Оно работает на устройствах владельца и использует выбранный им Google Drive.

Доступ и использование данных

Приложение запрашивает разрешение https://www.googleapis.com/auth/drive.file. Оно создаёт резервные копии, читает их метаданные, проверяет загрузки и скачивает копии для восстановления. Удаление собственных резервных копий может выполняться по правилам хранения, заданным владельцем. Данные используются исключительно для резервного копирования, проверки и восстановления.

Хранение и защита

Содержимое резервных копий шифруется на устройстве владельца перед отправкой в Google Drive. Учётные данные OAuth и ключи шифрования хранятся в защищённых конфигурационных файлах на устройствах владельца и в его отдельном комплекте восстановления. Они не публикуются на этом сайте.

Локальные служебные журналы могут содержать даты, имена файлов, размеры, контрольные суммы и результат операций. Они предназначены для диагностики бэкапов.

Передача и удаление

Резервные копии передаются в Google Drive выбранного аккаунта. Приложение не продаёт данные и не передаёт их рекламным или аналитическим сервисам. Данные Google не используются для обучения моделей машинного обучения. Этот информационный сайт размещается на GitHub Pages; обработка обращений к сайту регулируется также политикой GitHub.

Владелец может отозвать доступ приложения в настройках своего Google-аккаунта и удалить облачные и локальные копии. Отзыв OAuth-доступа сам по себе не удаляет уже сохранённые архивы.

Использование данных Google соответствует Google API Services User Data Policy, включая применимые требования Limited Use.
