Infra Backups

Личный инструмент для резервного копирования и восстановления конфигураций и виртуальных машин владельца. Это описание приложения, используемого одним владельцем на собственных устройствах; регистрации пользователей здесь нет.

Приложение использует rclone и Google Drive API для загрузки, проверки и скачивания резервных копий. Для облачного хранения применяется шифрование rclone crypt. Ключи шифрования хранятся отдельно от архивов.

Запрашивается разрешение Google Drive drive.file: управление файлами, созданными приложением или явно предоставленными ему пользователем. Доступ ко всем остальным файлам аккаунта не запрашивается.
